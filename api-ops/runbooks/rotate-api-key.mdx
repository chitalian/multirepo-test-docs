---
title: "Rotate the API key"
description: "Replace ACME_API_KEY without dropping traffic."
icon: "key-round"
---

The server accepts exactly one key at a time, so rotating means a short window where clients on the old key get `401`s.

<Steps>
  <Step title="Generate the new key">
    Create a new secret and store it in the secret manager next to the current one.
  </Step>
  <Step title="Tell client owners">
    Share the switch time. Clients need to read the key from config so they can change without a deploy.
  </Step>
  <Step title="Deploy with the new key">
    Set `ACME_API_KEY` to the new value and restart the service.
  </Step>
  <Step title="Watch for 401s">
    Follow [spike in 401s](/api-ops/runbooks/auth-failures) if errors don't drop within a few minutes.
  </Step>
</Steps>
