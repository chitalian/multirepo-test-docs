## What happens on a push

<Steps>
  <Step title="A team pushes to its repo">
    The repo's workflow notifies this repository.
  </Step>
  <Step title="The docs agent checks the change">
    If code changed, an AI agent reads the diff and updates the docs in every repository it affects, then pushes those doc changes.
  </Step>
  <Step title="The site repository syncs">
    `mintlify/multirepo-action` copies each repo's docs under its path, rewrites links, merges navigation, and commits to `main`.
  </Step>
  <Step title="Mintlify deploys">
    The site rebuilds from `main`, usually within a minute or two.
  </Step>
</Steps>

Automation is switched on per repository in `.github/docs-agent.yml`.
